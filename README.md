# Okba Bouziane — Portfolio

Personal portfolio of Okba Bouziane, full-stack developer (Angular, React, NestJS) building secure, AI-powered apps.

**Live:** https://devokba.vercel.app

## Pages

| Route | Content |
| --- | --- |
| `/` | Home — click the yin-yang for the intro |
| `/work` | Projects: [SecureMCP](https://github.com/okba-bouziane/SecureMCP) and [UniPath AI](https://github.com/okba-bouziane/UniPath) |
| `/experience` | Work experience and education |
| `/about` | About me |
| `/skills` | Skills |

All content (projects, experience, skills, links) lives in [`src/Data/profile.js`](src/Data/profile.js). The resume is served from `public/okba-resume.pdf`.

## Stack

React 18 · React Router 6 · styled-components · Framer Motion · tsParticles — deployed on Vercel.

## Development

```bash
npm install
npm start        # http://localhost:3000
npm test
npm run build
```
